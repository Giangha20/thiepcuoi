# 💍 WEBSITE THIỆP CƯỚI ONLINE CAO CẤP (LUXURY WEDDING INVITATION PLATFORM)

Một nền tảng website thiệp cưới online cao cấp, chuẩn thương mại, tinh tế và lãng mạn dành cho các cặp đôi. Hệ thống hoạt động thực tế 100% với cơ sở dữ liệu hoàn chỉnh, trang khách mời tương tác mượt mà và hệ thống quản trị CMS toàn diện giúp chỉnh sửa mọi nội dung mà không cần biết lập trình.

---

## 🌟 TÍNH NĂNG NỔI BẬT

### 1. Dành Cho Khách Mời (Guest View)
- ✉️ **Mở phong bì thiệp cưới 3D**: Phong bì sang trọng với con dấu sáp vàng (wax seal), hiệu ứng mở nắp mềm mại và mở thiệp chúc mừng.
- 🎵 **Nhạc nền lãng mạn**: Đĩa than quay nổi (floating vinyl player), phát nhạc tự động sau khi khách bấm mở thiệp, có nút bật/tắt và chọn bài.
- 🌸 **Hiệu ứng cánh hoa bay & bụi vàng**: Cánh hoa nhẹ nhàng rơi trên màn hình (sử dụng Canvas 60fps tối ưu, không giật lag, có thể tắt).
- 👰🤵 **Hồ sơ Cô Dâu & Chú Rể**: Chân dung sắc nét, tiểu sử, câu chuyện tình yêu, gia đình hai bên (Nhà Trai, Nhà Gái) và nút gọi điện trực tiếp.
- ⏳ **Đồng hồ đếm ngược**: Đếm ngược đến giây phút trọng đại (Ngày, Giờ, Phút, Giây). Tự động chuyển sang pháo hoa chúc mừng khi ngày cưới diễn ra.
- 📍 **Thông tin Lễ Cưới & Tiệc Cưới**: Hiển thị Lễ Vu Quy, Lễ Thành Hôn, Tiệc Cưới Mừng, địa chỉ chi tiết, tích hợp Google Maps chỉ đường và nút "Lưu vào Google Calendar".
- 📖 **Dòng thời gian tình yêu (Love Story Timeline)**: Kể lại từng cột mốc đáng nhớ (Lần đầu gặp gỡ, lần đầu hẹn hò, khoảnh khắc cầu hôn, ngày chung đôi) kèm hình ảnh.
- 📸 **Album ảnh cưới**: Bộ sưu tập hình ảnh độ phân giải cao, hỗ trợ xem phóng to (Lightbox toàn màn hình), lướt xem ảnh trước/sau và xem chú thích.
- ✍️ **Sổ lưu bút & Gửi lời chúc (Core Feature)**: 
  - Khách gửi lời chúc trực tiếp không cần đăng ký tài khoản.
  - Chọn biểu tượng cảm xúc (❤️, 🥂, 💐, 💍, 🎉, 🕊️).
  - Tích hợp chống spam (honeypot, rate limiting).
  - Lời chúc hiển thị ngay lập tức như những tấm thiệp nhỏ trang nhã.
  - Nút thả tim (Like) tăng tương tác trực tiếp.
- 🎁 **Hộp mừng cưới & Lì xì Online (VietQR)**: Tạo mã QR ngân hàng tự động cho Chú Rể & Cô Dâu, sao chép số tài khoản một chạm.
- 💌 **Lời cảm ơn & Chữ ký điện tử**: Thông điệp tri ân chân thành từ cặp đôi.
- 🔗 **Chia sẻ & Mã QR**: Chia sẻ trực tiếp qua Facebook, Zalo, Messenger, WhatsApp, tự động tạo mã QR thiệp cưới và tải ảnh QR PNG độ nét cao.
- 📱 **Tối ưu 100% trên Điện thoại**: Trải nghiệm vuốt chạm mượt mà trên iPhone, Android, Tablet và Desktop.

### 2. Trang Quản Trị Hệ Thống (Admin CMS Dashboard)
- 🔒 **Đăng nhập bảo mật**: Xác thực phiên làm việc JWT mã hóa an toàn, chống truy cập trái phép.

  - Tổng số phản hồi tham dự (RSVP) và tổng lượng khách dự kiến (headcount).
  - Tổng số lời chúc, danh sách lời chúc chờ duyệt.
  - Nhật ký hoạt động gần đây.
- 📝 **Quản lý Thông tin Cưới**: Chỉnh sửa tên, họ tên đầy đủ, ngày giờ cưới, lịch âm, lời mời, lời cảm ơn, ảnh đại diện, ảnh bìa lớn.

- 🖼️ **Quản lý Album ảnh cưới**: Tải ảnh trực tiếp từ máy tính lên hệ thống (Upload API thực tế), sửa chú thích, gắn nhãn ảnh nổi bật, xóa ảnh.

## 🛠️ CÔNG NGHỆ SỬ DỤNG

- **Framework**: Next.js 14 (App Router)
- **Ngôn ngữ**: TypeScript
- **Styling**: Tailwind CSS + Custom CSS Variables
- **Animations**: Framer Motion, Canvas Confetti
- **Icons**: Lucide Icons
- **Database & ORM**: Prisma ORM + SQLite (mặc định chạy ngay) / PostgreSQL & Supabase (cho production)
- **Bảo mật**: Jose JWT, BcryptJS password hashing
- **Xuất file**: SheetJS (XLSX)
- **Tạo mã QR**: QRCode Generator Engine

## 🚀 HƯỚNG DẪN CÀI ĐẶT & CHẠY DỰ ÁN

### 1. Yêu cầu môi trường
- Node.js version 18 trở lên (đã kiểm thử mượt mà trên Node v20/v22)
- Trình quản lý gói npm, yarn hoặc pnpm

### 2. Cài đặt thư viện
```bash
cd wedding-invitation
npm install
```

### 3. Cấu hình biến môi trường (`.env`)
File `.env` đã được cấu hình sẵn cho chế độ chạy cục bộ:
```env
DATABASE_URL="file:./dev.db"
JWT_SECRET="wedding-invitation-secret-key-super-secure-2026-luxurious-wedding"
NEXT_PUBLIC_APP_URL="http://localhost:3000"
```

### 4. Khởi tạo Cơ sở dữ liệu & Dữ liệu mẫu (Seed)
Chạy lệnh sau để đồng bộ database SQLite và tạo sẵn dữ liệu mẫu tuyệt đẹp kèm tài khoản quản trị:
```bash
npx prisma db push
npm run seed
```

### 5. Chạy ứng dụng

- **Chạy chế độ Development (Lập trình):**
```bash
npm run dev
```

- **Chạy chế độ Production (Tối ưu tốc độ cao nhất):**
```bash
npm run build
npm run start
```

Mở trình duyệt truy cập:
- **Trang thiệp cưới cho khách mời**: [http://localhost:3000](http://localhost:3000) hoặc [http://localhost:3000/thiep-cuoi/minh-anh-va-hoang-nam](http://localhost:3000/thiep-cuoi/minh-anh-va-hoang-nam)
- **Trang quản trị Admin**: [http://localhost:3000/admin](http://localhost:3000/admin)

## ☁️ HƯỚNG DẪN TRIỂN KHAI LÊN VERCEL & SUPABASE

### 1. Cấu hình Supabase PostgreSQL (Production Database)
1. Truy cập [https://supabase.com](https://supabase.com) và tạo một dự án mới.
2. Vào **Project Settings** -> **Database** -> sao chép chuỗi kết nối **URI (Connection String)** dạng:
   ```
   postgresql://postgres.[ref]:[password]@aws-0-ap-southeast-1.pooler.supabase.com:6543/postgres?pgbouncer=true
   ```
3. Trong file `prisma/schema.prisma`, đổi `provider = "sqlite"` thành `provider = "postgresql"`.
4. Cập nhật `DATABASE_URL` trong file `.env` với chuỗi kết nối trên.
5. Chạy lệnh:
   ```bash
   npx prisma db push
   npm run seed
   ```

### 2. Triển khai lên Vercel
1. Đẩy mã nguồn lên kho lưu trữ GitHub của bạn:
   ```bash
   git add .
   git commit -m "feat: Luxury Wedding Invitation Platform"
   git push origin main
   ```
2. Đăng nhập [https://vercel.com](https://vercel.com) -> Bấm **Add New** -> **Project** -> Chọn Repository GitHub của bạn.
3. Trong phần **Environment Variables**, cấu hình các biến sau:
   - `DATABASE_URL`: Đường dẫn database PostgreSQL/Supabase.
   - `JWT_SECRET`: Chuỗi khóa bảo mật ngẫu nhiên dài (ví dụ: `wedding_prod_secret_9988776655`).
   - `NEXT_PUBLIC_APP_URL`: Tên miền chính thức của bạn (ví dụ: `https://thiepcuoi.yourdomain.com`).
4. Bấm **Deploy**. Vercel sẽ tự động build và xuất bản website của bạn trong chưa đầy 2 phút!

## 🌐 HƯỚNG DẪN KẾT NỐI TÊN MIỀN RIÊNG (CUSTOM DOMAIN)

1. Mua tên miền tại các nhà cung cấp như PA Vietnam, Mat Bao, Cloudflare, Namecheap, GoDaddy (Ví dụ: `hoangnamminhanh.wedding` hoặc `damcuoi.vn`).
2. Trong trang quản lý dự án trên **Vercel** -> Vào tab **Settings** -> **Domains**.
3. Nhập tên miền của bạn (ví dụ: `thiepcuoi.hoangnamminhanh.com` hoặc `hoangnamminhanh.com`) -> Bấm **Add**.
4. Truy cập trang quản lý DNS tên miền của bạn và thêm bản ghi theo hướng dẫn của Vercel:
   - **Bản ghi CNAME**:
     - Host: `thiepcuoi` (hoặc `www`)
     - Value: `cname.vercel-dns.com`
   - Hoặc **Bản ghi A** (nếu dùng apex domain):
     - Host: `@`
     - Value: `76.76.21.21`
5. Vercel sẽ tự động cấp chứng chỉ SSL HTTPS miễn phí cho tên miền của bạn trong vòng vài phút.
